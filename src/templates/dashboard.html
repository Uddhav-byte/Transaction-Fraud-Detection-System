System Architecture

End-to-End Production ML Pipeline

01

Data Ingestion

Simulates realistic lognormal spending distributions across 7 merchant categories with 2% true fraud rate.

02

SMOTE Balancing

Generates synthetic minority fraud samples to eliminate severe imbalanced class bias during model training.

03

Ensemble decision trees tuned with balanced class weights, depth limit 20, and leaf regularization.

04
